How to Mine

Enter G.maps.tunnel.name from Mainland and stand still next to the mining rock so the zone is adjacent to you. Moving cancels the attempt (MP is still spent).

Mining channels for about 5–15 seconds. Most attempts find nothing. On a successful mine you get a reward and Mining goes on a long cooldown (~124 minutes). Failed attempts do not start that cooldown — you can try again after the channel ends.

Keep at least one free inventory slot. A successful mine with a full inventory still triggers the cooldown and can break the pickaxe — without giving an item.

CODE

Travel to the Mining Tunnel, equip a pickaxe, then mine when you are ready:

smart_move("tunnel") .then(function () { if (!character.slots.mainhand || character.slots.mainhand.name != "pickaxe") { var slot = locate_item("pickaxe"); if (slot == -1) return game_log("Need a Pickaxe"); equip(slot); } if (is_on_cooldown("mining") || character.mp < G.skills.mining.mp) return; if (!character.esize) return game_log("Inventory full"); use_skill("mining"); });

Only Merchants at level 16+ can use Mining. Stay still while the channel runs.

Rewards

Successful mining yields gem fragments and the occasional metal nugget (or a rare emotion).
