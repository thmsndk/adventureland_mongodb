Finding spots

Fishing only works next to a fishing zone on a map. Stand still beside the water — when you are close enough, an INFO button appears (rod icon). That means you are adjacent to a zone and can cast.

Each zone’s drop key picks its reward table under G.drops. Inspect map zones in CODE/data to find spots. Example:

  • G.maps.main.name ( G.maps.main.zones ) → G.drops.f1

Other fishing zones can use different drop tables — explore maps to find them.

How to Fish

Stand still at the water’s edge so the fishing zone is adjacent to you. Moving cancels the attempt (MP is still spent).

Casting channels for about 5–15 seconds. Most casts catch nothing. On a successful catch you get a reward and Fishing goes on a long cooldown (~48 minutes). Failed casts do not start that cooldown — you can try again after the channel ends.

Keep at least one free inventory slot. A successful catch with a full inventory still triggers the cooldown and can break the rod — without giving an item.

CODE

Travel to the shore fisherman, equip a rod, then cast when you are ready:

smart_move("fisherman") .then(function () { if (!character.slots.mainhand || character.slots.mainhand.name != "rod") { var slot = locate_item("rod"); if (slot == -1) return game_log("Need a Fishing Rod"); equip(slot); } if (is_on_cooldown("fishing") || character.mp < G.skills.fishing.mp) return; if (!character.esize) return game_log("Inventory full"); use_skill("fishing"); });

Only Merchants at level 16+ can use Fishing. Stay still while the channel runs.
