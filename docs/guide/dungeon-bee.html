G.monsters.bee_queen.explanation

The queen sits in the hive and does not roam. While engaged, she periodically calls G.monsters.bee_worker.names from spawn pads and G.monsters.bee_drone.names near herself. She also uses G.skills.bee_pheromones_queen_signal — pheromones that assign roles to nearby helpers (some lean toward attacking, others toward healing).

beekeeper

G.npcs.beekeeper.name

G.npcs.beekeeper

Stands near the mansion log on Main (by the dungeon entrance). Talk to them for quests, material trades, and a G.items.beetoken.name shop.

  • Kill quests

    One active target at a time — queen, workers, drones, or mainland bees. Counts and rewards scale with the target. Completing a quest pays G.items.beetoken.names.

  • Material trade

    G.items.bee_honey.name + G.items.bee_pollen.name craft Royal Jelly (G.craft.honeypot). G.items.bee_propolis.name helps seal the Bee Key (G.craft.beekey). Surplus honey, pollen, propolis, and G.items.beewings.name exchange for G.items.beetoken.names (dialogue: “Trade materials”).

  • Token shop
    G.items.honeypot G.items.honeypot1 G.items.beebox

    Honey pots, a G.items.beebox.name gamble for random set pieces, guaranteed set pieces for more tokens, and a rare unlock of the Beekeeper’s full look.

Automation Challenges

Try these coding challenges — each section has a short sketch to build on.

Entering a dungeon

Note: Most instances on this server stay available until the server restarts (unlike some solo-style instances that despawn when empty).

// Move to the dungeon entrance (Main, near the mansion log) smart_move('bee_dungeon') // Calling enter without an instance id consumes a key when opening a new instance: enter("bee_dungeon"); // Once opened, character.in is the instance id. Party members (or anyone you share it with) can enter: enter("bee_dungeon", character.in);

Making a party

One character opens the instance with a key; others join with the instance id.

// Inviting someone send_party_invite(name); // Handle when someone invites you function on_party_invite(name) { accept_party_invite(name); } // Requesting an invite from someone else send_party_request(name) // Handle when someone requests to join your party function on_party_request(name) { accept_party_request(name) }

Leaving a dungeon

Check G.maps.bee_dungeon.doors for exits — this dungeon has a door back to Main (mansion log spawn). On death, see G.maps.bee_dungeon.on_death / G.maps.bee_dungeon.on_exit.

// Path toward Main — the bee dungeon door leads to the mansion log spawn smart_move('main')

Kiting

Keep distance while monsters chase you — useful when many bees are aggressive at once.

General Mechanics

Fear

Your character can get feared in 3 stages: Scared, Terrified, Petrified. Each stage reduces movement speed and attack damage more than the last.

  • character.courage — max physical targets before getting scared
  • character.mcourage — max magical targets
  • character.pcourage — max pure targets
if (character.fear > 2) { // Your character is petrified } else if (character.fear > 1) { // Your character is terrified } else if (character.fear) { // your character is scared }
